Optional top-bar logos, one per provider: `<provider id>-symbolic.svg`
(e.g. `claude-symbolic.svg`, later `codex-symbolic.svg`).

- Single-color SVG; GNOME recolors `-symbolic` icons to match the top bar
  (and amber/red when quota runs low). ~16×16 viewBox works best.
- Missing file → the progress ring is shown instead.
- Logos are the owners' trademarks: fine for personal use, but leave them out
  of anything published to extensions.gnome.org unless you have permission.
